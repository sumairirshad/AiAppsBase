# Instagram Frontend

Next.js 16 (App Router) + TypeScript console for the Instagram publishing
tool. See [`../README.md`](../README.md) for full setup, architecture, and
feature documentation — this app is not meant to be run standalone without
the ASP.NET Core backend in `../backend`.

Quick start:

```bash
cp .env.example .env.local   # fill in INSTAGRAM_BACKEND_URL and INSTAGRAM_ADMIN_API_KEY
npm install
npm run dev                  # http://localhost:3100
```
